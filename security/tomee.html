Apache TomEE Security Vulnerabilities

This page lists the security vulnerabilities fixed in Apache TomEE releases. Each vulnerability is given a security impact rating by either the Apache TomEE team or by the dependent project supplying the fix - please note that this rating is not uniform and will vary from project to project. We also list the versions of Apache TomEE the flaw is known to affect, and where a flaw has not been verified list the version with a question mark.

Vulnerabilities that are not TomEE vulnerabilities but have either been incorrectly reported against TomEE or where TomEE provides a workaround are listed bellow in the section "Not a vulnerability".

Please note that binary patches are never provided. If you need to apply a source code patch, use the building instructions for the Apache TomEE version that you are using. Instructions for building TomEE from source are available here.

If you need help on building or configuring TomEE or other help on following the instructions to mitigate the known vulnerabilities listed here, please send your questions to the public Users mailing list

If you have encountered an unlisted security vulnerability or other unexpected behaviour that has security impact, or if the descriptions here are incomplete, please report them privately to the Apache Security Team. Thank you.

Fixed in Apache TomEE 10.3.0 and 11.0.0-M2

The following vulnerabilities were announced on 10 November 2026. All of them are resolved in Apache TomEE 10.3.0 and Apache TomEE 11.0.0-M2. Several fixes change default behavior. See the TomEE 10.3.0 migration guide and the TomEE 11.0.0-M2 migration guide before upgrading.

Vulnerabilities in removed modules

The following vulnerabilities affect optional modules that are no longer part of TomEE 10.3.0 and 11.0.0-M2: the embedded OpenEJB HTTP server (openejb-http) and the endpoints it published, the Hessian remoting module (openejb-hessian), and the SSH administration shell (openejb-ssh, openejb-common-cli). No fixed version of these modules exists. Upgrading to TomEE 10.3.0 or 11.0.0-M2 removes them. If you cannot upgrade, block network access to these services from untrusted clients or stop using them.

Details

Important: EJB method authorization is silently skipped on JDK 21+

CVE-2026-86336 - Announcement

Apache TomEE running on JDK 21 or later skips EJB method authorization checks, allowing callers to invoke EJB methods without the configured access restrictions being enforced.

Affected versions:

  • org.apache.tomee:openejb-core 10.1.1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Important: Authorization bypass in MicroProfile JWT role checks for JAX-RS resources

CVE-2026-111244 - Announcement

When MicroProfile JWT role-based access control is used, the access constraints of JAX-RS resources are not always enforced as declared: resources that declare an empty set of allowed roles are accessible to every caller, resource classes that inherit the same method from a common superclass share their constraints, and class-level constraints declared on a superclass are ignored. A remote attacker can invoke resources that should be denied to them, in some configurations without authentication.

Affected versions:

  • org.apache.tomee:mp-jwt 7.1.0 before 10.0.0-M1

  • org.apache.tomee:mp-jwt 10.0.0-M1 before 10.3.0

  • org.apache.tomee:mp-jwt 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Important: Well-known administrative credentials created at startup

CVE-2026-111257 - Announcement

With the default configuration and no users defined in the default user database, TomEE silently adds an administrative user with a well-known password at startup. A remote attacker can use these credentials to authenticate to web applications that use the default realm and grant access to any authenticated user or to the TomEE administrative role.

Affected versions:

  • org.apache.openejb:tomee-catalina 1.5.1 through 1.7.5

  • org.apache.tomee:tomee-catalina 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:tomee-catalina 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-catalina 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Important: Authentication bypass with empty password in LDAP identity store

CVE-2026-111261 - Announcement

The Jakarta Security LDAP identity store accepts an empty password as valid if the directory server allows unauthenticated binds, which some directory servers do by default. A remote attacker can then authenticate as any existing user without knowing the password.

Affected versions:

  • org.apache.tomee:tomee-security 8.0.4 before 10.0.0-M1

  • org.apache.tomee:tomee-security 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-security 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Important: Authentication bypass on EJB web service endpoints via HTTP method

CVE-2026-111264 - Announcement

The security constraint generated for EJB JAX-WS endpoints with configured authentication protects only some HTTP methods. A remote unauthenticated attacker can bypass authentication by sending requests with another HTTP method.

Affected versions:

  • org.apache.openejb:tomee-webservices 4.0.0-beta-1 through 4.0.0

  • org.apache.openejb:tomee-webservices 1.5.0 through 1.7.5

  • org.apache.tomee:tomee-webservices 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:tomee-webservices 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-webservices 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Jonathan Gallimore (remediation developer)

Moderate: Path traversal via stateful EJB passivation

CVE-2026-86811 - Announcement

The stateful session bean passivation mechanism derives the on-disk file name from a client-supplied identifier without validating it. A remote attacker with access to the remote EJB service can cause session state to be read from or written to files outside the passivation directory.

Affected versions:

  • org.apache.openejb:openejb-core 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-core 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-core 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: Stateful session bean hijacking via predictable session identifiers

CVE-2026-87755 - Announcement

Stateful session bean identifiers are not generated from a cryptographically secure random source. A remote attacker with access to the EJB remote endpoint who holds one valid identifier can derive those of other clients' sessions and invoke methods on their beans, exposing or modifying other users' session state.

Affected versions:

  • org.apache.openejb:openejb-core 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-core 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-core 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: Missing authorization on internal deployer EJBs in default profile

CVE-2026-87756 - Announcement

The internal system EJBs used for remote deployment and configuration did not enforce their administrative role check when the server ran with the default profile. A remote unauthenticated attacker able to reach the remote EJB endpoint could deploy arbitrary applications and execute code. Only installations that enabled the system applications and a remote EJB endpoint are exposed.

Affected versions:

  • org.apache.openejb:openejb-core 4.5.1 through 4.7.5

  • org.apache.tomee:openejb-core 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-core 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: Missing TLS hostname verification in ejbds client connections

CVE-2026-87758 - Announcement

The remote EJB client does not verify that the hostname of the server it connects to matches the server’s TLS certificate. An attacker able to intercept network traffic between an EJB client and server can impersonate the server and read or modify the traffic, including credentials and invocation data.

Affected versions:

  • org.apache.openejb:openejb-client 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-client 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-client 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-client 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: Derby network service listens on all interfaces

CVE-2026-97849 - Announcement

The embedded Derby network service ignores its configured bind address and listens on all network interfaces. When the service is enabled, a remote attacker with network access can connect to the database server and read or modify data.

Moderate: Database credential disclosure via remote JNDI lookup

CVE-2026-97867 - Announcement

The EJBd remote protocol returns datasource connection details, including database credentials, to remote clients that look up a datasource. A remote client able to reach the EJBd endpoint can obtain the database credentials and connect to the database directly.

Affected versions:

  • org.apache.openejb:openejb-ejbd 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-ejbd 7.0.0-M1 before 10.0.0-M1

Moderate: Authentication bypass for accounts without a stored password in SQL login module

CVE-2026-111240 - Announcement

The JDBC based JAAS login module accepts a login without a password for accounts whose stored password is NULL. A remote attacker who knows the user name of such an account can authenticate as that user and obtain its roles. Only deployments using this login module with NULL passwords in the user table are affected.

Affected versions:

  • org.apache.openejb:openejb-core 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-core 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-core 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Local code execution via predictable passivation files in the shared temporary directory

CVE-2026-111241 - Announcement

When a non-default stateful session bean passivation strategy is configured, passivated bean state is written to predictably named files in the shared system temporary directory, reusing files that already exist there, and is deserialized on activation. A local attacker who can write to that directory can read passivated session state or supply data that the server deserializes, potentially leading to code execution as the server process.

Affected versions:

  • org.apache.openejb:openejb-core 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-core 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-core 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-core 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Privilege escalation via leaked MicroProfile JWT run-as identity

CVE-2026-111242 - Announcement

When MicroProfile JWT authentication is used for servlets that declare a run-as identity, the security state established for a request is not always cleared from the processing thread when the request does not complete normally. A remote attacker holding a valid token can cause later, unrelated requests served by the same thread to invoke enterprise beans with the elevated run-as identity.

Affected versions:

  • org.apache.tomee:mp-jwt 8.0.0-M2 before 10.0.0-M1

  • org.apache.tomee:mp-jwt 10.0.0-M1 before 10.3.0

  • org.apache.tomee:mp-jwt 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Privilege escalation via WS-Security caller identity leaking between requests

CVE-2026-111245 - Announcement

After a successful WS-Security UsernameToken authentication, the caller identity stays associated with the worker thread once the request completes when web services are served by the standalone OpenEJB HTTP server. A remote unauthenticated attacker whose request is later processed on the same thread can invoke protected EJB methods with the identity of a previously authenticated user.

Affected versions:

  • org.apache.openejb:openejb-cxf 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-cxf 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-cxf 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-cxf 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Privilege escalation via user name matching a role name

CVE-2026-111247 - Announcement

When resolving security roles of a realm-authenticated caller, the caller’s user name is also treated as a role name in addition to the roles assigned by the realm. An authenticated attacker who can obtain an account whose user name equals a role name, for example through self-registration, is granted that role wherever authorization is evaluated through the Jakarta Authorization policy.

Affected versions:

  • org.apache.tomee:tomee-catalina 8.0.7 before 10.0.0-M1

  • org.apache.tomee:tomee-catalina 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-catalina 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Unauthenticated server shutdown via the admin port

CVE-2026-111251 - Announcement

The admin service of the standalone OpenEJB server accepts stop requests without any authentication. Any local user or process able to connect to the admin port can stop the server, leading to denial of service; the admin service is enabled by default in the standalone server and bound to the loopback interface.

Affected versions:

  • org.apache.openejb:openejb-server 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-server 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-server 10.0.0-M1 before 10.3.0

  • org.apache.tomee:openejb-server 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Moderate: Security constraint bypass via request routing

CVE-2026-111258 - Announcement

The optional request routing feature forwards requests to their configured destination without applying the security constraints of that destination or the protection of the web application’s private directories. If a route copies client-controlled parts of the request path into its destination, a remote attacker can reach protected resources or read application configuration and class files. Only installations with such a routing configuration are affected.

Affected versions:

  • org.apache.openejb:tomee-catalina 1.5.0 through 1.7.5

  • org.apache.tomee:tomee-catalina 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:tomee-catalina 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-catalina 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: Predictable HTTP session identifiers in embedded server

CVE-2026-111259 - Announcement

The embedded server generates HTTP session identifiers with a non-cryptographic random number generator by default. A remote attacker who observes a session identifier can predict the identifiers issued to other users and hijack their sessions, if the application relies on HTTP sessions for authentication.

Affected versions:

  • org.apache.tomee:tomee-embedded 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:tomee-embedded 10.0.0-M1 before 10.3.0

  • org.apache.tomee:tomee-embedded 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: LDAP injection in LDAP identity store

CVE-2026-111262 - Announcement

The Jakarta Security LDAP identity store does not neutralize special characters in the caller name before using it in directory queries. A remote unauthenticated attacker can alter the queries to enumerate accounts, infer directory attribute values, or influence which directory entry the login is validated against. Only applications using the LDAP identity store are affected.

Affected versions:

  • org.apache.tomee:tomee-security 10.0.0-M1 before 10.3.0

Authentication configured for an EJB JAX-WS endpoint in the TomEE deployment descriptor is not enforced when the endpoint is published within an existing web application. A remote unauthenticated attacker can invoke the web service operations, unless the application protects the endpoint with its own web.xml security constraints or EJB method permissions.

Low: Expired MicroProfile JWT tokens accepted with negative clock skew

CVE-2026-111243 - Announcement

A negative MicroProfile JWT clock skew setting is not rejected and disables validation of the token expiration and other time-based claims. In such configurations, an attacker in possession of an expired token can still authenticate with it.

Affected versions:

  • org.apache.tomee:mp-jwt 10.0.0-M1 before 10.3.0

Low: Authentication with the stored password digest in Tomcat user identity store

CVE-2026-111248 - Announcement

The Jakarta Security identity store backed by the Tomcat user database compares the supplied password with the stored value as plain text and ignores the configured credential handler. When digested passwords are stored, an attacker who obtained a stored digest, for example from a leaked users file or backup, can authenticate with the digest instead of the password.

Affected versions:

  • org.apache.tomee:tomee-security 8.0.0-M2 before 10.0.0-M1

  • org.apache.tomee:tomee-security 10.0.0-M1 before 10.3.0

Low: Unauthenticated LiveReload endpoint reachable from the network

CVE-2026-111249 - Announcement

The development-time LiveReload support listens on all network interfaces without authentication and accepts websocket connections from any origin. A network attacker, or a web page visited by the developer, can observe the names of changed files in the watched folder and the server version, and reach the deployed applications through the additional port. This only affects LiveReload enabled in the embedded Maven plugin.

Affected versions:

  • org.apache.tomee:livereload-tomee 7.0.0-M2 before 10.0.0-M1

  • org.apache.tomee:livereload-tomee 10.0.0-M1 before 10.3.0

  • org.apache.tomee:livereload-tomee 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Richard Zowalla (remediation developer)

Low: Predictable OpenID Connect state and nonce values

CVE-2026-111260 - Announcement

The Jakarta Security OpenID Connect authentication mechanism generates the state and nonce values with a non-cryptographic random number generator and insufficient entropy. A remote attacker who predicts these values can forge an authentication callback that logs a victim into the attacker’s account, and the replay protection for ID tokens is weakened.

Affected versions:

  • org.apache.tomee:tomee-security 10.0.0-M2 before 10.3.0

  • org.apache.tomee:tomee-security 11.0.0-M1 before 11.0.0-M2

Credit: The Apache Software Foundation (finder), Claude Security (tool), Markus Jung (remediation developer)

Moderate: DoS via unbounded request body and multipart handling in embedded HTTP server

CVE-2026-86531 - Announcement

The embedded OpenEJB HTTP server does not limit the size of incoming request bodies or of multipart requests, and does not remove the temporary files it creates for multipart parts. A remote unauthenticated attacker can cause excessive memory or disk usage, leading to denial of service. Deployments using the Tomcat connectors are not affected. Users are recommended to block network access to the embedded HTTP server from untrusted clients, or to migrate to the Tomcat based TomEE distributions.

Affected versions:

  • org.apache.openejb:openejb-http 4.0.0-beta-1 through 4.7.5

  • org.apache.tomee:openejb-http 7.0.0-M1 before 10.0.0-M1

  • org.apache.tomee:openejb-http 10.0.0-M1 through 10.2.0

Moderate: Code execution by any authenticated user via the SSH administration shell

The optional SSH administration service grants full access to the administration shell to every user that authenticates against its configured login domain, without checking for an administrative role.
